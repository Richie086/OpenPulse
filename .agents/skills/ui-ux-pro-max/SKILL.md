# UI/UX Pro Max Skill Guide

## Design System Architecture
1. **Glassmorphism & Cyber Aesthetics**:
   - Utilize backdrop blur (`backdrop-blur-xl`), translucent dark overlays (`bg-slate-900/80`), subtle white borders (`border-white/10`), and neon glowing accents (`shadow-cyan-500/10`).
2. **Shadcn Primitives First**:
   - Standardize UI containers around `<Card>`, `<CardHeader>`, `<CardTitle>`, `<CardDescription>`, `<CardContent>`, `<CardFooter>`, and `<Button>`.
3. **Responsive Grid Layouts**:
   - Organize dashboards using multi-column grid layouts (`grid-cols-1 lg:grid-cols-12`) with clear visual hierarchy.
4. **Interactive Micro-Interactions**:
   - Incorporate slow spin keyframes (`animate-spin-slow`), hover elevation (`hover:-translate-y-1`), and active state pills.
